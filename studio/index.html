        Looks

        A look is a named set of generation settings: workflow, prompt, style images, output and model choices. Each workflow keeps its own tuning inside a look. Fields use the default look unless a rule below or the Look menu picks another; a field can still change settings for itself on top.

        Assign by field name

        The first matching rule wins, checked against the field name and the maps that share its background. * matches anything: md* is every Midgar field, mds* the slums. Fields given a look directly keep it.
